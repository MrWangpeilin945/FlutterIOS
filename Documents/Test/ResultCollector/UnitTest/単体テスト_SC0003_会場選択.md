# SC0003_会場選択

## 初期表示

### 共通ヘッダー

#### 正常 未実施 コンポーネントの呼び出し
1. jotaiの職員名に「管理者　花子」を設定する
2. 会場選択画面を表示する
* [ ] 画面名に「会場選択」が表示されること
* [ ] ユーザーメニューの職員名に「管理者　花子」が表示されること

### 共通フッター

#### 正常 未実施 コンポーネントの呼び出し
1. 会場選択画面を表示する
* [ ] 1番目に「戻る」ボタンが表示されること
* [ ] 2番目以降は「空欄」ボタンが表示されること

### データ取得

#### 正常 未実施 AP1004_班を設定して会場日時を取得する
1. jotaiの班IDに「1」を設定する
2. 会場選択画面を表示する
* [ ] AP1004_班を設定して会場日時を取得するが呼び出されること
* [ ] クエリパラメータの「date」に「本日」の日付が「yyyy-MM-dd」で渡されること
* [ ] クエリパラメータの「teamid」に「1」が渡されること

#### 正常 未実施 AP1004_班を設定して会場日時を取得するのhttpステータスコードが「200」かつ 取得データが1件以上の場合
1. 会場選択画面を表示する
* [ ] エラーメッセージ「会場の設定がありませんでした。」が表示されないこと

#### 正常 未実施 AP1004_班を設定して会場日時を取得するのhttpステータスコードが「200」かつ 取得データが0件の場合
1. 会場選択画面を表示する
* [ ] エラーメッセージ「会場の設定がありませんでした。」が表示されること

#### 異常 未実施 AP1004_班を設定して会場日時を取得するのhttpステータスコードが「400」が返された場合
1. 会場選択画面を表示する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「必要なパラメータの入力形式が間違っています。」が表示されること

#### 異常 未実施 AP1004_班を設定して会場日時を取得するのhttpステータスコードが「500」が返された場合
1. 会場選択画面を表示する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「システム管理者にお問い合わせください。」が表示されること

### 見出しボタン

#### 正常 未実施 コンポーネントの呼び出し／jotaiの会場IDが未設定の場合
1. 会場選択画面を表示する
* [ ] 見出しボタンが表示されること
* [ ] 見出しボタンのタイトルにAP1004_班を設定して会場日時を取得するで取得した「placeName」が表示されること
* [ ] 見出しボタンの要素にAP1004_班を設定して会場日時を取得するで取得した「startTime」が表示されること
* [ ] 見出しボタンの色が反転しないで表示されること

#### 正常 未実施 コンポーネントの呼び出し／jotaiの班IDに「1」が設定されている場合
1. jotaiの会場IDに「1」を設定する
2. 会場選択画面を表示する
* [ ] 見出しボタンが表示されること
* [ ] 見出しボタンのタイトルにAP1004_班を設定して会場日時を取得するで取得した「placeName」が表示されること
* [ ] 見出しボタンの要素にAP1004_班を設定して会場日時を取得するで取得した「startTime」が表示されること
* [ ] AP1004_班を設定して会場日時を取得するで取得した「placeID」が「1」の見出しボタンの色が反転して表示されること
* [ ] AP1004_班を設定して会場日時を取得するで取得した「placeID」が「1」以外の見出しボタンの色が反転しないで表示されること

#### 正常 未実施 　
1. 会場選択画面を表示する
2. AP1004_班を設定して会場日時を取得するで取得データが0件の場合
* [ ] 見出しボタンが表示されないこと

## 見出しボタン押下

### 画面遷移

#### 正常 未実施 jotaiへの保存
1. 会場選択画面を表示する
2. 見出しボタンを押下する
* [ ] 選択した会場情報がjotaiに保存されること
* [ ] ホーム画面に遷移すること
