# SC0019_検査結果出力

## 初期表示

### 共通ヘッダー

#### 正常 未実施 コンポーネントの呼び出し
1. jotaiの職員名に「管理者　花子」を設定する
2. 検査結果出力画面を表示する
* [ ] 画面名に「検査結果出力」が表示されること
* [ ] ユーザーメニューの職員名に「管理者　花子」が表示されること

### 共通フッター

#### 正常 未実施 コンポーネントの呼び出し
1. 検査結果出力画面を表示する
* [ ] 1番目に「戻る」ボタンが表示されること
* [ ] 2番目と3番目は「空欄」ボタンが表示されること
* [ ] 4番目に「出力履歴」ボタンが表示されること

### データ取得

#### 正常 未実施 AP1018_連携対象の検査結果を取得する
1. 検査結果出力画面を表示する
* [ ] AP1018_連携対象の検査結果を取得するが呼び出されること

#### 正常 未実施 AP1018_連携対象の検査結果を取得するのhttpステータスコードが「200」かつ 取得データが1件以上の場合
1. 検査結果出力画面を表示する
* [ ] エラーメッセージ「検査結果データが存在しません。」が表示されないこと

#### 正常 未実施 AP1018_連携対象の検査結果を取得するのhttpステータスコードが「200」かつ 取得データが0件の場合
1. 検査結果出力画面を表示する
* [ ] エラーメッセージ「検査結果データが存在しません。」が表示されること

#### 異常 未実施 AP1018_連携対象の検査結果を取得するのhttpステータスコードが「500」の場合
1. 検査結果出力画面を表示する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「システム管理者にお問い合わせください。」が表示されること

### 検査結果情報

#### 正常 未実施 AP1018_連携対象の検査結果を取得するで取得データが1件以上の場合
1. 検査結果出力画面を表示する
* [ ] 検査結果情報が表示されること
* [ ] 検査結果情報の健診日にAP1018_連携対象の検査結果を取得するで取得した「examDate」が「yyyy/MM/dd」で表示されること
* [ ] 検査結果情報の会場にAP1018_連携対象の検査結果を取得するで取得した「placeName」が表示されること（折り返して表示）
* [ ] 検査結果情報の未にAP1018_連携対象の検査結果を取得するで取得した「status」が「11」（未出力）の「count」が表示されること
* [ ] 検査結果情報の保留にAP1018_連携対象の検査結果を取得するで取得した「status」が「21」（出力保留）の「count」が表示されること
* [ ] 検査結果情報の済にAP1018_連携対象の検査結果を取得するで取得した「status」が「31」（出力済み）の「count」が表示されること

#### 正常 未実施 AP1018_連携対象の検査結果を取得するのplaceScheduleLockingStatusが「21」の場合
1. 検査結果出力画面を表示する
* [ ] 検査結果情報の会場ロックボタンに「未」がオレンジ色で表示されること

#### 正常 未実施 AP1018_連携対象の検査結果を取得するのplaceScheduleLockingStatusが「31」の場合
1. 検査結果出力画面を表示する
* [ ] 検査結果情報の会場ロックボタンに「済」が青色で表示されること

#### 正常 未実施 AP1018_連携対象の検査結果を取得するで取得データが0件の場合
1. 検査結果出力画面を表示する
* [ ] 検査結果情報が表示されないこと

### 出力するボタン

#### 正常 未実施 AP1018_連携対象の検査結果を取得するのplaceScheduleLockingStatusが「21」の場合
1. 検査結果出力画面を表示する
* [ ] 出力するボタンが押下不可で表示されること
* [ ] 出力するボタンが灰色で表示されること

#### 正常 未実施 AP1018_連携対象の検査結果を取得するのplaceScheduleLockingStatusが「31」の場合
1. 検査結果出力画面を表示する
* [ ] 出力するボタンが押下可で表示されること
* [ ] 出力するボタンが緑色で表示されること

#### 正常 未実施 AP1018_連携対象の検査結果を取得するで取得データが0件の場合
1. 検査結果出力画面を表示する
* [ ] 出力するボタンが表示されないこと

## 会場ロックボタン押下

### 画面遷移

#### 正常 未実施 　
1. 検査結果出力画面を表示する
2. 会場ロックボタンを押下する
* [ ] 会場ロック画面に遷移すること

## 出力するボタン押下

### 確認ダイアログ

#### 正常 未実施 AP1018_連携対象の検査結果を取得するのplaceScheduleLockingStatusが「21」の場合
1. 検査結果出力画面を表示する
2. 出力するボタンを押下する
* [ ] 確認ダイアログが表示されないこと

#### 正常 未実施 AP1018_連携対象の検査結果を取得するのplaceScheduleLockingStatusが「31」の場合
1. 検査結果出力画面を表示する
2. 出力するボタンを押下する
* [ ] 確認ダイアログが表示されること
* [ ] 確認ダイアログのタイトルに「検査結果出力」が表示されること
* [ ] 確認ダイアログの登録日に検査結果情報の出力するボタンを押下した行の「健診日」が表示されること
* [ ] 確認ダイアログの会場に検査結果情報の出力するボタンを押下した行の「会場」が表示されること（折り返して表示）
* [ ] 確認ダイアログに戻るボタンと登録するボタンが表示されること

## 確認ダイアログ

### 戻るボタン押下

#### 正常 未実施 AP1019_連携用に検査結果を出力する
1. 検査結果出力画面を表示する
2. 出力するボタンを押下する
3. 確認ダイアログで戻るボタンを押下する
* [ ] 確認ダイアログが閉じること
* [ ] AP1019_連携用に検査結果を出力するが呼び出されないこと

### 登録するボタン押下

#### 正常 未実施 AP1019_連携用に検査結果を出力する
1. 検査結果出力画面を表示する
2. 出力するボタンを押下する
3. 確認ダイアログで登録するボタンを押下する
* [ ] 確認ダイアログが閉じること
* [ ] AP1019_連携用に検査結果を出力するが呼び出されること
* [ ] クエリパラメータの「placeScheduleId」にAP1018_連携対象の検査結果を取得するで取得した出力するボタンを押下した行の「placeScheduleId」が渡されること

#### 正常 未実施 AP1019_連携用に検査結果を出力するのhttpステータスコードが「200」が返された場合
1. 検査結果出力画面を表示する
2. 出力するボタンを押下する
3. 確認ダイアログで登録するボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] メッセージ「検査結果を出力しました。」が表示されること

#### 異常 未実施 AP1019_連携用に検査結果を出力するのhttpステータスコードが「400」が返された場合
1. 検査結果出力画面を表示する
2. 出力するボタンを押下する
3. 確認ダイアログで登録するボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「パラメータの入力形式が間違っています。」が表示されること

#### 異常 未実施 AP1019_連携用に検査結果を出力するのhttpステータスコードが「404」が返された場合
1. 検査結果出力画面を表示する
2. 出力するボタンを押下する
3. 確認ダイアログで登録するボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「出力情報が存在しません。」が表示されること

#### 異常 未実施 AP1019_連携用に検査結果を出力するのhttpステータスコードが「500」が返された場合
1. 検査結果出力画面を表示する
2. 出力するボタンを押下する
3. 確認ダイアログで登録するボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「システム管理者にお問い合わせください。」が表示されること

## 出力履歴ボタン押下

### 画面遷移

#### 正常 未実施 　
1. 検査結果出力画面を表示する
2. 出力履歴ボタンを押下する
* [ ] 検査結果出力履歴画面に遷移すること
