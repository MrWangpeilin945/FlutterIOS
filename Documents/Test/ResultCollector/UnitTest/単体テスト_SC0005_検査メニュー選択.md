# SC0005_検査メニュー選択

## 初期表示

### 共通ヘッダー

#### 正常 未実施 コンポーネントの呼び出し
1. jotaiの職員名に「管理者　花子」を設定する
2. 検査メニュー選択画面を表示する
* [ ] 画面名に「検査メニュー選択」が表示されること
* [ ] ユーザーメニューの職員名に「管理者　花子」が表示されること

### 共通フッター

#### 正常 未実施 コンポーネントの呼び出し
1. 検査メニュー選択画面を表示する
* [ ] 1番目に「戻る」ボタンが表示されること
* [ ] 2番目以降は「空欄」ボタンが表示されること

### データ取得

#### 正常 未実施 AP1006_検査メニュー一覧を取得する
1. 検査メニュー選択画面を表示する
* [ ] AP1006_検査メニュー一覧を取得するが呼び出されること

#### 正常 未実施 AP1006_検査メニュー一覧を取得するのhttpステータスコードが「200」かつ 取得データが1件以上の場合
1. 検査メニュー選択画面を表示する
* [ ] エラーメッセージ「検査メニューの設定がありませんでした。」が表示されないこと

#### 正常 未実施 AP1006_検査メニュー一覧を取得するのhttpステータスコードが「200」かつ 取得データが0件の場合
1. 検査メニュー選択画面を表示する
* [ ] エラーメッセージ「検査メニューの設定がありませんでした。」が表示されること

#### 異常 未実施 AP1006_検査メニュー一覧を取得するのhttpステータスコードが「500」が返された場合
1. 検査メニュー選択画面を表示する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「システム管理者にお問い合わせください。」が表示されること

### 検査メニュー項目ボタン

#### 正常 未実施 jotaiの検査メニューが設定されている場合
1. jotaiの検査項目IDに「11」を設定する
2. jotaiの検査項目IDに「12」を設定する
3. jotaiの検査項目IDに「13」を設定する
4. 検査メニュー選択画面を表示する
* [ ] 検査メニュー項目ボタンが表示されること
* [ ] 検査項目IDが「11」の検査メニュー項目ボタンに「1」が表示され色が反転して表示されること
* [ ] 検査項目IDが「12」の検査メニュー項目ボタンに「2」が表示され色が反転して表示されること
* [ ] 検査項目IDが「13」の検査メニュー項目ボタンに「3」が表示され色が反転して表示されること
* [ ] 検査項目IDが「11」、「12」、「13」以外の検査メニュー項目ボタンに数字が表示されず色が反転しないで表示されること

#### 正常 未実施 jotaiの検査メニューが未設定の場合
1. 検査メニュー選択画面を表示する
* [ ] 検査メニュー項目ボタンが表示されること
* [ ] 検査メニュー項目ボタンに数字が表示されず色が反転しないで表示されること

#### 正常 未実施 AP1006_検査メニュー一覧を取得するで取得したexamMenuNameが9文字未満の場合
4. 検査メニュー選択画面を表示する
* [ ] 検査メニュー項目ボタンが表示されること
* [ ] 検査メニュー項目ボタンの検査項目名にAP1006_検査メニュー一覧を取得するで取得した「examMenuName」が表示されること

#### 正常 未実施 AP1006_検査メニュー一覧を取得するで取得したexamMenuNameが9文字以上の場合
1. 検査メニュー選択画面を表示する
* [ ] 検査メニュー項目ボタンが表示されること
* [ ] 検査メニュー項目ボタンの検査項目名にAP1006_検査メニュー一覧を取得するで取得した「examMenuName」が8文字目まで表示されること

#### 正常 未実施 AP1006_検査メニュー一覧を取得するで取得データが0件の場合
1. 検査メニュー選択画面を表示する
* [ ] 検査メニュー項目ボタンが表示されないこと

### 開始するボタン

#### 正常 未実施 AP1006_検査メニュー一覧を取得するで取得データが1件以上の場合
1. 検査メニュー選択画面を表示する
* [ ] 開始するボタンが表示されること

#### 正常 未実施 AP1006_検査メニュー一覧を取得するで取得データが0件の場合
1. 検査メニュー選択画面を表示する
* [ ] 開始するボタンが表示されないこと

## 検査メニュー項目ボタン押下

### 検査メニュー項目ボタン

#### 正常 未実施 検査メニュー項目ボタンを1個選択する場合
1. 検査メニュー選択画面を表示する
2. 検査メニュー項目ボタンを押下する
* [ ] 押下した検査メニュー項目ボタンに「1」が表示され色が反転して表示されること

#### 正常 未実施 検査メニュー項目ボタンを5個選択する場合
1. 検査メニュー選択画面を表示する
2. 検査メニュー項目ボタンを5個押下する
* [ ] 押下した順に検査メニュー項目ボタンに数字が表示され色が反転して表示されること

#### 正常 未実施 検査メニュー項目ボタンを5個選択し3番目に選択したボタンを未選択にする場合
1. 検査メニュー選択画面を表示する
2. 検査メニュー項目ボタンを5個押下する
3. 3番目に押下した検査メニュー項目ボタンを押下する
* [ ] 3番目に押下した検査メニューボタンに数字が表示されず色が反転しないで表示されること
* [ ] 1番目と2番目に押下した検査メニューボタンの数字は変更されずに色が反転して表示されること
* [ ] 4番目に押下した検査メニューボタンに「3」が表示され色が反転して表示されること
* [ ] 5番目に押下した検査メニューボタンに「4」が表示され色が反転して表示されること

#### 正常 未実施 検査メニュー項目ボタンを5個選択し3番目に選択したボタンを未選択にし別の検査メニュー項目ボタンを選択する場合
1. 検査メニュー選択画面を表示する
2. 検査メニュー項目ボタンを5個押下する
3. 3番目に押下した検査メニュー項目ボタンを押下する
4. 未選択の検査メニュー項目ボタンを押下する
* [ ] 3番目に押下した検査メニューボタンに数字が表示されず色が反転しないで表示されること
* [ ] 1番目と2番目に押下した検査メニューボタンの数字は変更されずに色が反転して表示されること
* [ ] 4番目に押下した検査メニューボタンに「3」が表示され色が反転して表示されること
* [ ] 5番目に押下した検査メニューボタンに「4」が表示され色が反転して表示されること
* [ ] 最後に押下した検査メニューボタンに「5」が表示され色が反転して表示されること

## 開始するボタン押下

### 開始するボタン

#### 正常 未実施 検査メニュー項目ボタンを1個以上選択した場合
1. 検査メニュー選択画面を表示する
2. 検査メニュー項目ボタンを押下する
3. 開始するボタンを押下する
* [ ] 押下した検査メニュー項目ボタンの検査項目IDと検査項目名が押下した順にjotaiに保存されること
* [ ] 受診番号入力画面に遷移すること

#### 正常 未実施 検査メニュー項目ボタンを未選択の場合
1. 検査メニュー選択画面を表示する
2. 開始するボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「検査メニューが選択されていません。」が表示されること
* [ ] 共通ダイアログのボタンに「閉じる」が表示されること
* [ ] 受診番号入力画面に遷移しないこと
