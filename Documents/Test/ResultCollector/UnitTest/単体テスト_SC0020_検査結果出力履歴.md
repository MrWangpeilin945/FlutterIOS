# SC0020_検査結果出力履歴

## 初期表示

### 共通ヘッダー

#### 正常 未実施 コンポーネントの呼び出し
1. jotaiの職員名に「管理者　花子」を設定する
2. 検査結果出力履歴画面を表示する
* [ ] 画面名に「検査結果出力履歴」が表示されること
* [ ] ユーザーメニューの職員名に「管理者　花子」が表示されること

### 共通フッター

#### 正常 未実施 コンポーネントの呼び出し
1. 検査結果出力履歴画面を表示する
* [ ] 1番目に「戻る」ボタンが表示されること
* [ ] 2番目と3番目は「空欄」ボタンが表示されること
* [ ] 4番目に「出力」ボタンが表示されること

### データ取得

#### 正常 未実施 AP1020_検査結果の出力履歴を取得する
1. 検査結果出力履歴画面を表示する
* [ ] AP1020_検査結果の出力履歴を取得するが呼び出されること

#### 正常 未実施 AP1020_検査結果の出力履歴を取得するのhttpステータスコードが「200」かつ 取得データが1件以上の場合
1. 検査結果出力履歴画面を表示する
* [ ] エラーメッセージ「出力済みのデータが存在しません。」が表示されないこと

#### 正常 未実施 AP1020_検査結果の出力履歴を取得するのhttpステータスコードが「200」かつ 取得データが0件の場合
1. 検査結果出力履歴画面を表示する
* [ ] エラーメッセージ「出力済みのデータが存在しません。」が表示されること

#### 異常 未実施 AP1020_検査結果の出力履歴を取得するのhttpステータスコードが「400」の場合
1. 検査結果出力履歴画面を表示する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「パラメータの入力形式が間違っています。」が表示されること

#### 異常 未実施 AP1020_検査結果の出力履歴を取得するのhttpステータスコードが「500」の場合
1. 検査結果出力履歴画面を表示する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「システム管理者にお問い合わせください。」が表示されること

### 出力履歴情報

#### 正常 未実施 AP1020_検査結果の出力履歴を取得するで取得データが1件以上の場合
1. 検査結果出力履歴画面を表示する
* [ ] 出力履歴情報が表示されること
* [ ] 出力履歴情報の出力者にAP1020_検査結果の出力履歴を取得するで取得した「exportedBy」が表示されること（折り返して表示）
* [ ] 出力履歴情報の健診日にAP1020_検査結果の出力履歴を取得するで取得した「examDate」が「yyyy/MM/dd」で表示されること
* [ ] 出力履歴情報の会場にAP1020_検査結果の出力履歴を取得するで取得した「placeName」が表示されること（折り返して表示）
* [ ] 出力履歴情報の件数にAP1020_検査結果の出力履歴を取得するで取得した「dataCount」が表示されること
* [ ] 出力履歴情報に未出力にするボタンが表示されること

#### 正常 未実施 AP1020_検査結果の出力履歴を取得するで取得データが0件の場合
1. 検査結果出力履歴画面を表示する
* [ ] 出力履歴情報が表示されないこと

## 未出力にするボタン押下

### 確認ダイアログ

#### 正常 未実施 　
1. 検査結果出力履歴画面を表示する
2. 未出力にするボタンを押下する
* [ ] 確認ダイアログが表示されること
* [ ] 確認ダイアログのタイトルに「検査結果出力履歴」が表示されること
* [ ] 確認ダイアログの健診日に出力履歴情報の未出力にするボタンを押下した行の「健診日」が表示されること
* [ ] 確認ダイアログの会場に出力履歴情報の未出力にするボタンを押下した行の「会場」が表示されること（折り返して表示）
* [ ] 確認ダイアログの件数に出力履歴情報の未出力にするボタンを押下した行の「件数」が表示されること
* [ ] 確認ダイアログに戻るボタンと未出力にするボタンが表示されること

## 確認ダイアログ

### 戻るボタン押下

#### 正常 未実施 AP1021_検査結果の連携状態を未出力にする
1. 検査結果出力履歴画面を表示する
2. 未出力にするボタンを押下する
3. 確認ダイアログで戻るボタンを押下する
* [ ] 確認ダイアログが閉じること
* [ ] AP1021_検査結果の連携状態を未出力にするが呼び出されないこと

### 未出力にするボタン押下

#### 正常 未実施 AP1021_検査結果の連携状態を未出力にする
1. 検査結果出力履歴画面を表示する
2. 未出力にするボタンを押下する
3. 確認ダイアログで未出力にするボタンを押下する
* [ ] 確認ダイアログが閉じること
* [ ] AP1021_検査結果の連携状態を未出力にするが呼び出されること
* [ ] リクエストボディの「exportId」にAP1020_検査結果の出力履歴を取得するで取得した未出力にするボタンを押下した行の「exportId」が渡されること

#### 正常 未実施 AP1021_検査結果の連携状態を未出力にするのhttpステータスコードが「200」が返された場合
1. 検査結果出力履歴画面を表示する
2. 未出力にするボタンを押下する
3. 確認ダイアログで未出力にするボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] メッセージ「未出力状態に変更しました。」が表示されること

#### 異常 未実施 AP1021_検査結果の連携状態を未出力にするのhttpステータスコードが「400」が返された場合
1. 検査結果出力履歴画面を表示する
2. 未出力にするボタンを押下する
3. 確認ダイアログで未出力にするボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「パラメータの入力形式が間違っています。」が表示されること

#### 異常 未実施 AP1021_検査結果の連携状態を未出力にするのhttpステータスコードが「404」が返された場合
1. 検査結果出力履歴画面を表示する
2. 未出力にするボタンを押下する
3. 確認ダイアログで未出力にするボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「変更情報が存在しません。」が表示されること

#### 異常 未実施 AP1021_検査結果の連携状態を未出力にするのhttpステータスコードが「500」が返された場合
1. 検査結果出力履歴画面を表示する
2. 未出力にするボタンを押下する
3. 確認ダイアログで未出力にするボタンを押下する
* [ ] 共通ダイアログが表示されること
* [ ] エラーメッセージ「システム管理者にお問い合わせください。」が表示されること
