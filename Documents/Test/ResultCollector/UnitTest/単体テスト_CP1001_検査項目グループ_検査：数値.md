## value の値が変更された時

### エラーメッセージ

#### 正常 未実施 value に空の値が設定された場合

1. 検査項目グループ_検査：数値コンポーネントが呼び出される
2. 入力値テキストボックスを押下する。
3. キーボード(整数)が表示される。
4. 数字ボタンを押下する。
5. クリアボタンを押下する。

* [ ] エラーメッセージ「{検査項目}は入力必須項目です。」が文字色をテーマの"error"で表示されていること

#### 正常 未実施 value に半角数字以外の値が設定された場合

1. 検査項目グループ_検査：数値コンポーネントが呼び出される
2. 入力値テキストボックスを押下する。
3. デバイスキーボードで「a」を入力する。

* [ ] エラーメッセージ「{検査項目}は半角数字で入力してください。」が文字色をテーマの"error"で表示されていること

#### 正常 未実施 value に設定された値が引数.検査項目情報.examItem の positionNumber が「1」の要素の examItemDetails の positionNumber が「1」の要素の examNormalValueRanges の errorLevel:3 に該当する場合

1. 引数の examNormalValueRanges に{errorLevel:3, maxValue:100.0,minValue:0.0}を設定する。
2. 検査項目グループ_検査：数値コンポーネントが呼び出される
3. 入力値テキストボックスを押下する。
4. 数字ボタンの「1」を押下する。

* [ ] エラーメッセージ「{検査項目}は半角数字で入力してください。」が文字色をテーマの"error"で表示されていること

#### 正常 未実施 value に設定された値が引数.検査項目情報.examItem の positionNumber が「1」の要素の examItemDetails の positionNumber が「1」の要素の examNormalValueRanges の errorLevel:2 に該当する場合

1. 引数の examNormalValueRanges に{errorLevel:2, maxValue:100.0,minValue:0.0}を設定する。
2. 検査項目グループ_検査：数値コンポーネントが呼び出される
3. 入力値テキストボックスを押下する。
4. 数字ボタンの「1」を押下する。

* [ ] エラーメッセージ「入力値を確認してください。」が文字色をテーマの"warning"で表示されていること
