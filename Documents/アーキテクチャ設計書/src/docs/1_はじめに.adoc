= はじめに

== 本ドキュメントの目的

WELLSHIPのアーキテクチャ設計に関する指針を示す。

- 基本設計以降のインプットにする
- 継続してプロダクトを成長させるために保守容易性を高める
- アーキテクチャに関する決定および変更の履歴を残す

システムの全体構成やと各アプリケーションの設計方針を記載する。
アプリケーション基盤としての共通機能についても取り扱う。

== 本ドキュメントのスコープ

WELLSHIPシリーズ第1弾である結果収集をスコープとする。
ただし、アプリケーションの動作に必要な共通基盤機能については将来を見越して設計する。

変更や追記が必要な場合は、その都度プルリクエストを出して更新する。
