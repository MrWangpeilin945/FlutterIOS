== EC2011_職員を登録する

=== 概要

* 外部連携で使用する
* 引数の職員をDBに登録する

=== 処理フロー

[mermaid]
----
flowchart TD
    A[UseCase] --> ERROR{ERROR検証}
    ERROR -- エラーあり --> C(ErrorObject生成、追加)
    ERROR -- エラー無 --> WARNING{WARNING検証}    
    WARNING -- ワーニングあり --> DROP(WARNINGレコードDrop)
    DROP(WARNINGレコードDrop) --> DROP_REC(ErrorObject生成、追加)
    DROP_REC --> D[[Repository]]
    WARNING -- ワーニング無 --> D
    C --> E(返却)
    D --> E
    E --> UseCaseEND(END)

    F[[Repository]] --> G[BEGIN]
    G --> H1["Upsert(一括):[DB]staffs(職員)"]
    H1 --> K[Commit]
    H1 -.Exception.-> ROLLBACK[ROLLBACK]
    K --> RepositoryEND[[END]]
    ROLLBACK .-> RepositoryEND
----

=== 非機能

* 1万レコードの登録を10秒以内に完了する
* DB登録に失敗した場合、全てロールバックする

==== WARNING検証

* 必須項目(Staff.StaffCode)が空値
** `Staff.StaffCode` が `string.IsNullOrWhiteSpace` に該当する 
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10004`
**** Message `必須項目が不足しています。StaffCode`
**** InputNote `Staff.InputNote`

* 必須項目(Staff.LoginId)が空値
** `Staff.LoginId` が `string.IsNullOrWhiteSpace` に該当する 
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10004`
**** Message `必須項目が不足しています。LoginId`
**** InputNote `Staff.InputNote`

* 必須項目(Staff.Password)が空値
** `Staff.Password` が `string.IsNullOrWhiteSpace` に該当する 
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10004`
**** Message `必須項目が不足しています。Password`
**** InputNote `Staff.InputNote`

* 必須項目(Staff.Name)が空値
** `Staff.Name` が `string.IsNullOrWhiteSpace` に該当する 
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10004`
**** Message `必須項目が不足しています。Name`
**** InputNote `Staff.InputNote`

* 項目(Staff.LoginId)制限：文字数
** `Staff.LoginId` の文字数 `> 20` に該当する 
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10005`
**** Message `制限数を超えています。LoginId:[Staff.LoginId]`
**** InputNote `Staff.InputNote`

* 項目(Staff.Password)制限：文字数
** `Staff.Password` の文字数 `> 20` に該当する 
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10005`
**** Message `制限数を超えています。Password:[Staff.Password]`
**** InputNote `Staff.InputNote`

* 項目(Staff.LoginId)制限：形式
** `Staff.LoginId` の `a-zA-Z0-9` 以外の文字を含む 
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10006`
**** Message `値の形式が無効です。LoginId:[Staff.LoginId]`
**** InputNote `Staff.InputNote`

* ユニークキー(Staff.StaffCode)が重複するレコードが存在する
** Staffsを以下の条件でGroupByし、複数レコードが存在する
**** `Staff.StaffCode`
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10003`
**** Message `キー項目が重複しています。StaffCode:[Staff.StaffCode]`
**** InputNote `Staff.InputNote`

* ユニークキー(Staff.LoginId)が重複するレコードが存在する
** Staffsを以下の条件でGroupByし、複数レコードが存在する
**** `Staff.LoginId`
*** Staffの単位で該当を取り除く
*** ErrorObject
**** Code `10003`
**** Message `キー項目が重複しています。LoginId:[Staff.LoginId]`
**** InputNote `Staff.InputNote`

* ログインIDが異なる職員コードで登録されている
** `[DB]staffs.login_id (ログインID)` == `Staff.LoginId` && `[DB]staffs.staff_code(職員コード)` != `Staff.StaffCode` が存在する
*** Staffの単位で該当を取り除く
*** ErrorObject
*** Code `10002`
**** Message `指定されたLoginIdが既に登録済みです。Code:[Staff.LoginId]` 
**** InputNote `Staff.InputNote`

** `created_at` に登録する `system.datetime.now()`
** `created_by` に登録する `'ExternalConnection'`
