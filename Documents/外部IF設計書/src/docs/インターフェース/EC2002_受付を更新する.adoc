== EC2002_受付を更新する

=== 概要

* 外部連携で使用する
* 引数の受付をDBに登録する

=== 処理フロー

[mermaid]
----
flowchart TD
    A[UseCase] --> ERROR{ERROR検証}
    ERROR -- エラーあり --> C(ErrorObject生成、追加)
    ERROR -- エラー無 --> WORNING{WORNING検証}    
    WORNING -- ワーニングあり --> DROP(WORNINGレコードDrop)
    DROP(WORNINGレコードDrop) --> DROP_REC(ErrorObject生成、追加)
    DROP_REC --> D[[Repository]]
    WORNING -- ワーニング無 --> D
    C --> E(返却)
    D --> E
    E --> UseCaseEND(END)

    F[[Repository]] --> G[BEGIN]
    G --> H["Update(一括):[DB]consult(受診)"]
    H --> I["Upsert(一括):[DB]tickets(受付)"]
    I --> J["Insert(一括):[DB]tickets_histories(受付履歴)"]
    J --> K[Commit]
    H -.Exception.-> ROLLBACK[ROLLBACK]
    G -.Exception.-> ROLLBACK
    I -.Exception.-> ROLLBACK
    J -.Exception.-> ROLLBACK
    K --> RepositoryEND[[END]]
    ROLLBACK .-> RepositoryEND
----

=== 非機能

* 1万レコードの登録を10秒以内に完了する
* 検証・DB登録に失敗した場合、全てロールバックする

==== ERROR検証

==== WORNING検証

* 連携キーの取得に失敗
** `[DB]consult(受診).external_connection_code(外部連携キー) == Ticket.ConnectionCode` が存在しない
*** ErrorObject
*** Code `10002`
**** Message `指定されたConnectionCodeシステム上に存在しません。Code:[Consult.external_connection_code]` 
**** InputNote [Ticket.InputNote]

=== 処理(Repository)

==== ワークテーブル登録

* `Ticket` をワークテーブルに登録する。
* `Ticket.ConnectionCode` でグループ化し、 `Ticket.SortNo` が最大のレコードで `[DB]consult(受診)` と `[DB]tickets(受付)` の更新処理を行う。


==== 登録処理

*  `[DB]tickets_histories(受付履歴)` は全レコード更新を行う。

* 条件①
** `Ticket.ConnectionMode  == 追加`

* [DB]consult(受診)
