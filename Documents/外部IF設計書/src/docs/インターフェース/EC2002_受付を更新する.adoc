== EC2002_受付を更新する

=== 概要

* 外部連携で使用する
* 引数の受付をDBに登録する

=== 処理フロー

[mermaid]
----
flowchart TD
    A[UseCase] --> ERROR{ERROR検証}
    ERROR -- エラーあり --> C(ErrorObject生成、追加)
    ERROR -- エラー無 --> WARNING{WARNING検証}    
    WARNING -- ワーニングあり --> DROP(WARNINGレコードDrop)
    DROP(WARNINGレコードDrop) --> DROP_REC(ErrorObject生成、追加)
    DROP_REC --> D[[Repository]]
    WARNING -- ワーニング無 --> D
    C --> E(返却)
    D --> E

    F[[Repository]] --> G[BEGIN]

    I --> J["Dalete(一括):[DB]tickets(受付)"]

=== 非機能

* 1万レコードの登録を10秒以内に完了する
* 検証・DB登録に失敗した場合、全てロールバックする

==== ERROR検証

* None

==== WARNING検証

* 連携キーの取得に失敗
** `[DB]consult(受診).external_connection_code(外部連携キー)` == `Ticket.ConnectionCode` And `[DB]consult(受診).progress_status(進捗状況)` In  (`11` (ConsultProgressStatus.来場待ち) , `21` (ConsultProgressStatus.検査中)) が存在しない
*** Ticketの単位で該当を取り除く
*** ErrorObject
*** Code `10001`
**** Message `指定されたConnectionCodeがシステム上に存在しません。Code:[Ticket.ConnectionCode]` 
**** InputNote `Ticket.InputNote`

=== 処理(Repository)

* `Ticket.ConnectionCode` でグループ化し、 `Ticket.SortNo` が最大のレコードでを処理対象とする
** ただし、`[DB]tickets_histories(受付履歴)` は全レコード追加(履歴として管理するため)

* 下記の登録値は、呼びもとで指定する
** `created_at` に登録する `system.datetime.now()`
** `created_by` に登録する `'ExternalConnection'`

** `Ticket.ActionType` == `ActionType.登録` And +
