== EC2011_職員を登録する

=== 概要

* 外部連携で使用する
* 引数の職員をDBに登録する

=== 処理フロー

[mermaid]
----
flowchart TD
    A[UseCase] --> ERROR{ERROR検証}
    ERROR -- エラーあり --> C(ErrorObject生成、追加)
    ERROR -- エラー無 --> WARNING{WARNING検証}    
    WARNING -- ワーニングあり --> DROP(WARNINGレコードDrop)
    DROP(WARNINGレコードDrop) --> DROP_REC(ErrorObject生成、追加)
    DROP_REC --> D[[Repository]]
    WARNING -- ワーニング無 --> D
    C --> E(返却)
    D --> E
    E --> UseCaseEND(END)

    F[[Repository]] --> G[BEGIN]
    G --> H1["Upsert(一括):[DB]staffs(職員)"]
    H1 --> K[Commit]
    H1 -.Exception.-> ROLLBACK[ROLLBACK]
    K --> RepositoryEND[[END]]
    ROLLBACK .-> RepositoryEND
----

=== 非機能

* 1万レコードの登録を10秒以内に完了する
* DB登録に失敗した場合、全てロールバックする

==== 処理(Repository)

* 下記の登録値は、呼びもとで指定する
** `created_at` に登録する `system.datetime.now()`
** `created_by` に登録する `'ExternalConnection'`

===== Table

* [DB]staffs(職員)

===== Upsert

* 競合条件
** `[DB]staffs.staff_code(職員コード)` == `Staff.StaffCode` OR `[DB]staffs.login_id(ログインID)` == `Staff.LoginId`
