== EC2013_基準パターンを登録する

=== 概要

* 外部連携で使用する
* 引数の基準パターンをDBに登録する

=== 処理フロー

[mermaid]
----
flowchart TD
    A[UseCase] --> B{検証}
    B -- エラーあり --> C(ErrorObject生成、追加)
    B -- エラー無 --> D[[Repository]]
    C --> E(返却)
    D --> E
    E --> UseCaseEND(END)

    F[[Repository]] --> G[BEGIN]
    G --> H["Upsert(一括):[DB]thresholds(基準パターン)"]
    H --> K[Commit]
    H -.Exception.-> ROOLBACK[ROOLBACK]
    K --> RepositoryEND[[END]]
    ROOLBACK .-> RepositoryEND
----

=== 非機能

* 1万レコードの登録を10秒以内に完了する
* 検証・DB登録に失敗した場合、全てロールバックする

=== UseCase

[source]
----
StoreThresholdsAsync
----

==== 処理(Repository)

===== Insert

* 条件
** `[DB]thresholds(基準パターン).threshold_code(基準パターンコード) == Threshold.Code` が存在しない

===== Table

* [DB]thresholds(基準パターン)

[cols="1,2,2" options="header"]
|===
|列|登録値|処理・変換

|team_id
|max([DB]thresholds(基準パターン).threshold_id(基準パターンID)) + 1
|

|threshold_code
|Threshold.Code
|

|name
|Threshold.Name
|

|order_number
|max([DB]thresholds(基準パターン).order_number(表示順)) + 1
|

|created_at
|system.datetime.now()
|

|created_by
|`'ExternalConnection'`
|

|===
