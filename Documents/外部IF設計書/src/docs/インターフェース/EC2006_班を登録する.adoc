== EC2006_班を登録する

=== 概要

* 外部連携で使用する
* 引数の班をDBに登録する

=== 処理フロー

[mermaid]
----
flowchart TD
    A[UseCase] --> ERROR{ERROR検証}
    ERROR -- エラーあり --> C(ErrorObject生成、追加)
    ERROR -- エラー無 --> WARNING{WARNING検証}    
    WARNING -- ワーニングあり --> DROP(WARNINGレコードDrop)
    DROP(WARNINGレコードDrop) --> DROP_REC(ErrorObject生成、追加)
    DROP_REC --> D[[Repository]]
    WARNING -- ワーニング無 --> D
    C --> E(返却)
    D --> E
    E --> UseCaseEND(END)

    F[[Repository]] --> G[BEGIN]
    G --> H["Upsert(一括):[DB]teams(班)"]
    H --> K[Commit]
    H -.Exception.-> ROLLBACK[ROLLBACK]
    K --> RepositoryEND[[END]]
    ROLLBACK .-> RepositoryEND
----

=== 非機能

* 1万レコードの登録を10秒以内に完了する
* DB登録に失敗した場合、全てロールバックする

==== 列挙型

* None

==== ERROR検証

* None

==== WARNING検証

* ユニークキー(Team.Code)が重複するレコードが存在する
** Teamsを以下の条件でGroupByし、複数レコードが存在する
**** `Team.Code`
*** Teamの単位で該当を取り除く
*** ErrorObject
**** Code `10003`
**** Message `キー項目が重複しています。Code:[Team.Code]`
**** InputNote `Team.InputNote`

==== 処理(Repository)

* 下記の登録値は、呼びもとで指定する
** `created_at` に登録する `system.datetime.now()`
** `created_by` に登録する `'ExternalConnection'`
