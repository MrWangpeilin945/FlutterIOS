== EC2007_会場を登録する

=== 概要

* 外部連携で使用する
* 引数の会場をDBに登録する

=== 処理フロー

[mermaid]
----
flowchart TD
    A[UseCase] --> B{検証}
    B -- エラーあり --> C(ErrorObject生成、追加)
    B -- エラー無 --> D[[Repository]]
    C --> E(返却)
    D --> E
    E --> UseCaseEND(END)

    F[[Repository]] --> G[BEGIN]
    G --> H["Upsert(一括):[DB]places(会場)"]
    H --> K[Commit]
    H -.Exception.-> ROOLBACK[ROOLBACK]
    K --> RepositoryEND[[END]]
    ROOLBACK .-> RepositoryEND
----

=== 非機能

* 1万レコードの登録を10秒以内に完了する
* 検証・DB登録に失敗した場合、全てロールバックする
