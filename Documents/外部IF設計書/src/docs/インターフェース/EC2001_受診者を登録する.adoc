== EC2001_受診者を登録する

=== 概要

* 外部連携で使用する
* 引数の受診者をDBに登録する

=== 処理フロー

[mermaid]
----
flowchart TD
    A[UseCase] --> ERROR{ERROR検証}
    ERROR -- エラーあり --> C(ErrorObject生成、追加)
    ERROR -- エラー無 --> WORNING{WORNING検証}    
    WORNING -- ワーニングあり --> DROP(WORNINGレコードDrop)
    DROP(WORNINGレコードDrop) --> DROP_REC(ErrorObject生成、追加)
    DROP_REC --> D[[Repository]]
    WORNING -- ワーニング無 --> D
    C --> E(返却)
    D --> E
    E --> UseCaseEND(END)

    F[[Repository]] --> G[BEGIN]
    G --> H["Upsert(一括):[DB]examinees(受診者)"]
    H --> I["Delete(一括):[DB]affiliations(所属)"]
    I --> J["Insert(一括):[DB]affiliations(所属)"]
    J --> K[Commit]
    H -.Exception.-> ROOLBACK[ROOLBACK]
    G -.Exception.-> ROOLBACK
    J -.Exception.-> ROOLBACK
    K --> RepositoryEND[[END]]
    ROOLBACK .-> RepositoryEND
----

=== 非機能

* 1万レコードの登録を10秒以内に完了する
* DB登録に失敗した場合、全てロールバックする

StoreExamineesAsync

==== 列挙型

==== ERROR検証

* None

==== WORNING検証

* 団体が取得できない
** `[DB]organizations(団体).organization_code(団体コード) == Examinee.Affiliations.OrganizationCode` が存在しない
*** Examineeの単位で該当を取り除く
*** ErrorObject
**** Code `10001`
**** Message `指定されたOrganizationCodeがシステム上に存在しません。Code:[Examinee.Affiliations.OrganizationCode]`
**** InputNote [Examinee,InputNote]

==== 処理(Repository)

* 下記の登録値は、呼びもとで指定する
** `created_at` に登録する `system.datetime.now()`
** `created_by` に登録する `'ExternalConnection'`

===== Table

* [DB]affiliations(所属)

** [DB]affiliations(所属)は[DB]examinees(受診者)サブテーブルとして扱うため、
[DB]examinees(受診者)更新時にDelete/Insertを行う

====== Delete

登録前に `[DB]affiliations(所属).examinee_id == 追加・更新体対象に含まれる[DB]examinees(受診者).examinee_id` を削除する
