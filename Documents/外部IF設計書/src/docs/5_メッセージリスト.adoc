= メッセージリスト

ErrorObjectに指定されるメッセージリストを指定します。


[options="header",cols="1,1,3,3"]
|===

|AlertLevel
|Code
|Message
|出力例

|Warning
|`10001`
|`指定されたコードがマスタに登録されていません。[項目1]:[登録値1] .... /[項目N]:[登録値N]`
|`指定されたコードがマスタに登録されていません。ThresholdCd:12345`

|Warning
|`10002`
|`指定されたコードが既に登録されています。[項目1]:[登録値1] .... /[項目N]:[登録値N]`
|`指定されたコードが既に登録されています。ConsultNumber:No-200415-1`

|Warning
|`10003`
|`重複したコードが存在します。[項目1]:[登録値1] .... /[項目N]:[登録値N]`
|`重複したコードが存在します。PreviousResults.ExamItemDetailCd:PREVI-200415-X/PreviousResults.ExamDate:2024/11/22`

|Warning
|`10004`
|`値が登録されていません。[項目]`
|`値が登録されていません。StaffCode`

|Warning
|`10005`
|`値の文字数が不正です。[項目]:[登録値]`
|`値の文字数が不正です。LoginId:S20110989012345678901`

|Warning
|`10006`
|`不正な形式の値です。[項目]:[登録値]`
|`不正な形式の値です。LoginId:S201111$`

|Warning
|`10007`
|`値の範囲が不正です。[項目1]:[登録値1] .... /[項目N]:[登録値N]`
|`値の範囲が不正です。MinAge:0500000/MaxAge:0400000`

|===
