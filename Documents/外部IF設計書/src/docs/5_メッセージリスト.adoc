= メッセージリスト

ErrorObjectに指定されるメッセージリストを指定します。


[options="header",cols="1,1,3,3"]
|===

|AlertLevel
|Code
|Message
|出力例

|Warning
|`10001`
|`指定された[項目名]がシステム上に存在しません。Code:[登録値]`
|`指定されたThresholdCdがシステム上に存在しません。Code:12345`

|Warning
|`10002`
|`指定された[項目名]が既に登録済みです。Code:[登録値]`
|`指定されたConsultNumberが既に登録済みです。Code:No-200415-1`

|Warning
|`10003`
|`キー項目が重複しています。[項目1]:[登録値1] .... /[項目N]:[登録値N]`
|`キー項目が重複しています。PreviousResults.ExamItemDetailCd:PREVI-200415-X/PreviousResults.ExamDate:2024/11/22`

|Warning
|`10004`
|`必須項目が不足しています。[項目]`
|`必須項目が不足しています。StaffCode`

|Warning
|`10005`
|`制限数を超えています。[項目]:[登録値]`
|`制限数を超えています。LoginId:S20110989012345678901`

|Warning
|`10006`
|`値の形式が無効です。[項目]:[登録値]`
|`値の形式が無効です。LoginId:S201111$`

|Warning
|`10007`
|`値の範囲が無効です。[項目1]:[登録値1] .... /[項目N]:[登録値N]`
|`値の範囲が無効です。MinAge:0500000/MaxAge:0400000`

|===
