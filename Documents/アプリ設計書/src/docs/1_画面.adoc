== 起動画面

=== メニュー

image::menu.png[メニュー画面]

アプリを直接起動した場合に表示します。
画面に表示したボタンをタップすると、選んだ通信方式の設定画面に遷移します。

---

=== ディープリンクホーム画面

アプリをWEBから起動した場合に使用します。
起動時のURLに付与したクエリパラメータを元に設定を読み込み、有線・Bluetooth SPPの通信画面に遷移します。
直ちに通信画面に遷移するため、この画面にUIは組みません。

== 有線通信機能

端末とシリアル通信デバイスを有線ケーブルで接続して通信する機能です。

---

=== 設定画面

image::wired_settings.png[有線設定画面]

画面下部の「読み取り開始」ボタンを押すことで通信画面に遷移します。

==== 設定可能な項目

[cols="20,~"]
|===

|設定項目 |備考
|ボーレート| 入力ダイアログ
|データビット数| 選択ダイアログ
|パリティビット| 選択ダイアログ
|ストップビット| 選択ダイアログ
|DTRを使用する|トグルスイッチ
|RTSを使用する|トグルスイッチ
|Ack文字列|表示のみ
|Ack送信条件文字列|表示のみ
|終了条件文字列|表示のみ
|終了条件バイト数|表示のみ

|===

---

=== 通信画面

USBポートからシリアル通信ケーブルを探し、通信を待ち受ける画面です。
通信終了条件（終端文字・受信データ長）を満たしたとき、
コールバックURLの設定があればそのURLにクエリパラメータで受信結果を追加してブラウザで開きます。

image::wired.png[有線通信画面]

[cols="20,~"]
|===

|コントロール | 備考
|画面タイトル| デフォルトでは「有線接続通信画面」が表示されますが、読み取り画面タイトルが設定されていればその内容を表示します。
|接続先| 使用するUSBケーブルのパスを表示しています。
|ステータス|ケーブル未接続時は「準備中」、ケーブル接続後は「準備完了」が表示されます。
|テキストエリア|受信した内容をテキストエリアに描画します。

|===

== Bluetooth SPP通信機能

端末とシリアル通信デバイスをBluetooth SPPで接続して通信する機能です。

---

=== 設定画面

image::spp_settings.png[SPP設定画面]

「接続デバイス」から通信先の機器を選択した状態で画面下部の「読み取り開始」ボタンを押すことで通信画面に遷移します。

==== 設定可能な項目

[cols="20,~"]
|===

|設定項目 |備考
|接続デバイス|右端の↺をタップするとデバイスを再検索します。
|Ack文字列|表示のみ
|Ack送信条件文字列|表示のみ
|終了条件文字列|表示のみ
|終了条件バイト数|表示のみ

|===

---

=== 通信画面

指定したデバイスをBluetoothで探し、接続して通信を待ち受ける画面です。
通信終了条件（終端文字・受信データ長）を満たしたとき、
コールバックURLの設定があればそのURLにクエリパラメータで受信結果を追加してブラウザで開きます。

image::spp.png[SPP通信画面]

[cols="20,~"]
|===

|コントロール | 備考
|画面タイトル| デフォルトでは「BluetoothClassic接続通信画面」が表示されますが、読み取り画面タイトルが設定されていればその内容を表示します。
|接続先| 指定したデバイスの名前・MACアドレスを表示します。選択したデバイスの名前とアドレスはアプリに保存され、次回以降起動時も初期状態で同じデバイスに接続を試行します。
|ステータス|Bluetooth接続未確立時は「準備中」、接続後は「準備完了」が表示されます。
|テキストエリア|受信した内容をテキストエリアに描画します。

|===
