= ユースケース

ユースケースの設計を示します。

ユースケースはコントローラーから利用されます。リクエストモデルを受け取り、レスポンスモデルを返却します。

リポジトリを通してデータベースにアクセスします。ドメインモデルに定義されたロジックを利用しつつ、処理の流れを記載します。

== 認証ユースケース

[mermaid,Authentication-u-cd,png]
----
classDiagram
class AuthenticationUsecase {
  + Login(request)
}
----

=== Login_ログインする

[mermaid,Login-u-seq,png]
----
sequenceDiagram
  participant con as Controller
  participant uc as Usecase
  participant repo as Repository

  con->>uc: 職員ID、パスワード
  uc->>repo: GetStaff()
  repo-->>uc: Staff
  alt 職員が存在しない
    uc->>uc: カスタム例外を投げる
  end
  uc->>uc: パスワード検証
  alt パスワードが一致する
    uc->>con: アクセストークン
  else パスワードが一致しない
    uc->>uc: カスタム例外を投げる
  end
----
