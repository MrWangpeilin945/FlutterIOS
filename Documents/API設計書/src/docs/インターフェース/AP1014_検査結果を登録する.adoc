== AP1014_検査結果を登録する

=== 概要

* 検査結果入力画面から利用する
* 検査結果入力画面で入力した検査結果を保存する
* 会場日程がロック中のとき、管理者ロールのみ更新できる

=== URI

[source]
----
[POST] /consult/{consultNumber}/results
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|00123

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "examMenuId" : 10,
  "examResults" : [
    {
      "examItemId": 12,
      "examItemDetails" : [
        {
          "examItemDetailId": 1,
          "value" : "120"
        },
        {
          "examItemDetailId": 2,
          "value" : ""
        }
      ]
    }
  ]
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
* 400 BadRequest
** リクエストボディの形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 403 Forbidden
** 会場日程がロック中のため更新権限がない
* 404 NotFound
** 指定した受診が存在しない
