== AP1015_進捗状況を取得する

=== 概要

* 受診と検査項目明細を指定して検査結果を取り消す
* 検査結果テーブルから削除されて検査結果削除履歴テーブルに移動する
* 指定した検査項目明細の結果レコードがない場合でもエラーにはしない

=== URI

[source]
----
[POST] /consult/{consultNumber}/results/batchDelete
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|00123

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
    "examItemDetailIds": [
        123,
        124,
        223,
        224
    ]
}
----

=== レスポンスボディ

なし

=== ステータスコード

* No Content
** 結果取り消しが完了
* 400 BadRequest
** リクエストボディの形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 403 Forbidden
** 会場日程がロック中のため更新権限がない
* 404 NotFound
** 指定した受診が存在しない
