== AP1022_検査の実施有無と中止理由を登録する

=== 概要

* 受診の検査項目ごとに実施有無と中止理由を記録するため
* 検査内容確認画面から利用する
* 検査実施しない（`isPerforming:false`）の場合は中止理由ID（`cancelReasonId`）を合わせて送付する
* 検査項目単位でリクエストするが、データベースでは検査項目明細単位で中止理由を保持する
** 検査項目明細マスタを参照して、指定した検査項目に紐づく検査項目明細を取得する
** ただし検査依頼がある検査項目明細に対してのみ、中止レコードを登録する
* 会場日程がロック中のとき、管理者ロールのみ更新できる

=== URI

[source]
----
[POST] /consult/{consultNumber}/executions
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|00123

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "executions": [
    {
      "examItemId": 3,
      "isPerforming" : ture,
      "cancelReasonId": null
    },
    {
      "examItemId": 3,
      "isPerforming" : false,
      "cancelReasonId": 3
    }
  ]
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
* 400 BadRequest
** リクエストボディの形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 403 Forbidden
** 会場日程がロック中のため更新権限がない
* 404 NotFound
** 指定した受診が存在しない
