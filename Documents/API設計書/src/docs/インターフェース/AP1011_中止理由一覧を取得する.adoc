== AP1011_中止理由一覧を取得する

=== 概要

* 検査内容確認画面で入力する中止理由を取得する
* 中止理由の表示順の昇順でソートする
* 検査項目IDを渡すと絞り込みできる

=== URI

[source]
----
[GET] /cancelReasons
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "cancelReasons": [
    {
      "cancelReasonId": 1,
      "cancelReasonName": "中止理由A",
      "examItemId": 23
    },
    {
      "cancelReasonId": 2,
      "cancelReasonName": "中止理由B",
      "examItemId": 23
    }
  ]
}
----

=== ステータスコード

* 200 OK
* 400 BadRequest
** 検査項目IDの形式が不正
* 401 Unauthorized
** JWT認証に失敗
