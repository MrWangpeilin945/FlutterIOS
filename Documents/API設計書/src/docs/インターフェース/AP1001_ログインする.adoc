== AP1001_ログインする

=== 概要

* 職員IDとパスワードを渡して認証用のトークンを取得する
* テナントIDはサブドメインから取得するため、リクエストボディでは扱わない

=== URI

[source]
----
[POST] /staff/login
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "loginId": "ABC12345",
  "password": "sKgj3c83JXJWXs"
}
----

=== レスポンスヘッダ

==== Cookie

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|refreshToken
|Yes
|string
|リフレッシュトークン(HTTPOnly)
|`1234567890abcdef...`

|===

=== レスポンスボディ

[source,json]
----
{
  "token":"cgNUZ8ZP5prD2g..."
}

----

=== ステータスコード

* 200 OK
* 403 Forbidden
** ログインが拒否された場合
