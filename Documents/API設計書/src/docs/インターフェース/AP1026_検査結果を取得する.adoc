== AP1026_検査結果を取得する

=== 概要

* 受診者の今回値と過去の検査情報を取得する

=== URI

[source]
----
[GET] /consult/{consultNumber}/results
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|00123

|===

=== クエリパラメータ

なし

=== リクエストボディ

なし
