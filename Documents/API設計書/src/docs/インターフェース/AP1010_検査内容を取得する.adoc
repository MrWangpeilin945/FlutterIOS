== AP1010_検査内容を取得する

=== 概要

* 検査内容確認画面から利用する
* 受診番号（consultNumber）から受診者に関する情報を取得する
* 検査メニューID（examMenuId）から検査メニューに関する情報を取得する

=== URI

[source]
----
[GET] /consult/{consultNumber}/examItems
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|`012345678`

|===

=== クエリパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|examMenuId
|Yes
|number
|検査メニューID
|3

|===

=== リクエストボディ

なし

=== ステータスコード

* 200 OK
* 400 BadRequest
** 指定した受診番号の形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 404 NotFound
** 指定した受診が存在しない
