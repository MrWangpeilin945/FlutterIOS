== AP1004_班を指定して会場日程を取得する

=== 概要

* 会場選択画面から利用する
* 班を指定して会場日程を取得する
* 会場日程リストは会場の表示順＞開始時刻の昇順でソートする

=== URI

[source]
----
[GET] /placeSchedules/places
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|date
|Yes
|string
|当日の会場日程を絞り込む
|`2024-09-25`

|teamId
|Yes
|number 
|選択した班で絞り込む
|`15`

|===

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "teamId": 15,
  "teamName": "J班",
  "examDate": "2024-09-25",
  "placeSchedules": [
    {
      "placeScheduleId": 10,
      "placeId": 1,
      "placeName": "会場A",
      "startTime": "09:00"
    },
    {
      "placeScheduleId": 15,
      "placeId": 4,
      "placeName": "会場D",
      "startTime": "13:00"
    }
  ]
}
----

=== ステータスコード

* 200 OK
* 400 BadRequest
** 必須パラメータ不足
* 401 Unauthorized
** JWT認証に失敗
