== AP1005_ホームメニュー項目を取得する

=== 概要

* ホーム画面の表示に必要なホームメニューを取得する
* ホームメニューの項目は設定したグループでグルーピングする
* グループとグループ内の項目は表示順の昇順でソートする
* メニューごとに使用可能条件を設定する。すべての条件を満たすメニューを利用できる。ただし空リストの場合は制限なく使用できる。
** `placeScheduleSelected`: 会場日程が選択済みである
** `placeScheduleUnlocked`: 会場ロックが解除されている

=== URI

[source]
----
[GET] /homeMenus
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|placeScheduleId
|No
|int
|会場日程ID。指定した場合は、会場ロック状況を取得して返却する。
|`25`

|===

=== リクエストボディ

なし
