== AP1020_検査結果の出力履歴を取得する

=== 概要

* 検査結果を出力した履歴を取得する
* 出力日時の降順でソートする

=== URI

[source]
----
[GET] /integrations/examResults/exportHistory
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "exportHistories": [
    {
      "exportId" : "c0873b41-ac80-403e-ae35-336065b0411f"
      "placeScheduleId": "ed282fd3-8ef5-426a-b1c3-c2a0fced1c13",
      "placeName": "会場B",
      "placeScheduleLockingStatus" : 1,
      "examDate": "2024-10-21",
      "dataCount": 187,
      "exportedAt": "2024-11-14T18:05:00+09:00",
      "exportedBy": "両備 太郎"
    }
  ]
}
----

=== ステータスコード

* 200 OK
* 401 Unauthorized
** JWT認証に失敗

=== 並び順

* 検査結果出力履歴.出力日時の降順
