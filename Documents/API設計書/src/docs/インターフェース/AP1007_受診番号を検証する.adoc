== AP1007_受診番号を検証する

=== 概要

* 受診番号入力画面から利用する
* 受診番号の受診が存在するかどうか確認する
* 受診が存在するかのみ確認してその他の責務を持たない

=== URI

[source]
----
[POST] /consult/consultNumber/verify
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "consultNumber": "15"
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
** 入力した受診番号の受診データが存在する
* 400 BadRequest
** リクエストボディの形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 404 NotFound
** 入力した受診番号の受診データが存在しない
