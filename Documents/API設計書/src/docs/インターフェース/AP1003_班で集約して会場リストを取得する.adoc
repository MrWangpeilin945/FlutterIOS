== AP1003_班で集約して会場リストを取得する

=== 概要

* 班選択画面から利用する
* 班と会場リストを取得する
* 班の並び順、会場の並び順の昇順でソートする

=== URI

[source]
----
[GET] /placeSchedules/teams
----

=== リクエストヘッダー

=== パスパラメータ

=== クエリパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|date
|Yes
|string
|操作日当日を渡して会場日程を絞り込む
|`2024-09-25`

|===

=== リクエストボディ

なし
