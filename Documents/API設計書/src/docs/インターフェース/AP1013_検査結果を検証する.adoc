== AP1013_検査結果を検証する

=== 概要

* 検査結果入力画面から利用する
* 検査結果入力画面の入力値のバリデーションチェックをする
* バリデーションエラーメッセージを返却する

=== URI

[source]
----
[POST] /consult/{consultNumber}/results/verify
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|00123

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "examMenuId" : 10,
  "examResults" : [
    {

=== ステータスコード

* 200 OK
* 400 BadRequest
** 指定した受診番号の形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 404 NotFound
** 指定した受診が存在しない
* 422 Unprocessable
** バリデーションエラー
