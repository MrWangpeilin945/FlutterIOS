== AP1023_ログイン状態を更新する

=== 概要

* アクセストークンとリフレッシュトークンを渡して新しい認証用のトークンを取得する
* リフレッシュトークンは``[POST] /staff/login``のレスポンスでhttponlyのcookieとして返却したものを使用する
* テナントIDはサブドメインから取得するため、リクエストボディでは扱わない

=== URI

[source]
----
[POST] /staff/login/refresh
----

=== リクエストヘッダー

==== Cookie

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|refreshToken
|Yes
|string
|リフレッシュトークン
|`1234567890abcdef...`

|===

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "token": "eyJ..."
}
----

=== レスポンスヘッダ

==== Cookie

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|refreshToken
|Yes
|string
|リフレッシュトークン(HTTPOnly)
|`1234567890abcdef...`

|===

=== レスポンスボディ

[source,json]
----
{
  "token":"eyJ..."
}

----

=== ステータスコード

* 200 OK
* 401 Unauthorized
** 誤ったアクセストークンを受け取った場合
** 誤ったリフレッシュトークンを受け取った場合
** リフレッシュトークンの有効期限が切れていた場合
