== AP1021_検査結果の連携状態を変更する

=== 概要

* 会場日程単位の連携状態を変更する
* 結果出力後に連携状態を引き戻して再処理したいときなどに使用する
* 未出力にする場合、`placeScheduleResultExportStatus : 11`を送信する
* バックエンドでは、受診ごとに持っているステータス（`consultResultExportStatus`）を更新する

=== URI

[source]
----
[PUT] /placeSchedules/{placeScheduleId}/placeScheduleResultExportStatus
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|placeScheduleId
|Yes
|int
|会場日程ID
|23

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "placeScheduleId": 15,
  "placeScheduleResultExportStatus": 1
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
* 400 BadRequest
** 指定した受診番号の形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 404 NotFound
** 指定した受診が存在しない
