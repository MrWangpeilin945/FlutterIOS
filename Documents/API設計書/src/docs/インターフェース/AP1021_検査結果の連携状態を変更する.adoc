== AP1021_検査結果の連携状態を未出力にする

=== 概要

* 出力結果履歴に対して、受診データ出力状況「出力済み」を「未出力」に変更する
* 検査結果出力履歴画面から利用する
* 指定した出力IDが存在しない場合は、何も更新せずエラーも出さない

=== URI

[source]
----
[PUT] /integrations/examResults/undoExport
----

=== リクエストヘッダー

=== パスパラメータ

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "exportId": "c0873b41-ac80-403e-ae35-336065b0411f",
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
* 400 BadRequest
** 指定した出力IDがUUIDの形式ではない
* 401 Unauthorized
** JWT認証に失敗
