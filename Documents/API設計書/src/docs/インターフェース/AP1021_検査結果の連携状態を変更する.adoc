== AP1021_検査結果の連携状態を未出力にする

=== 概要

* 出力結果履歴に対して、受診データ出力状況「出力済み」を「未出力」に変更する
* 検査結果出力履歴画面から利用する

=== URI

[source]
----
[PUT] /integrations/examResults/{placeScheduleId}/undo
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|placeScheduleId
|Yes
|int
|会場日程ID
|23

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "exportId": "c0873b41-ac80-403e-ae35-336065b0411f",
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
* 400 BadRequest
** 指定した会場日程IDの形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 404 NotFound
** 指定した会場日程が存在しない
