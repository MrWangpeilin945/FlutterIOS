== AP1006_検査メニュー一覧を取得する

=== 概要

* 検査メニューを選択するための一覧表示に利用する

=== URI

[source]
----
[GET] /examMenus
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "examMenus": [
    {
      "examMenuId":12,
      "examMenuName":"身体計測"
    },
    {
      "examMenuId":21,
      "examMenuName":"血圧"
    }
  ]
}
----

=== ステータスコード

* 200 OK
* 401 Unauthorized
** JWT認証に失敗

=== 並び順

* 検査メニュー.表示順の昇順
