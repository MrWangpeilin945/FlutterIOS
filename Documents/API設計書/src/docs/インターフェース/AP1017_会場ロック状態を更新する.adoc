== AP1017_会場ロック状態を更新する

=== 概要

* 会場ロックの状態を更新して登録する
* `placeScheduleLockingStatus` は会場日程状況 （ `PlaceScheduleLockingStatus` ）を使用する

=== URI

[source]
----
[PUT] /placeSchedules/{placeScheduleId}/placeScheduleLockingStatus
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|placeScheduleId
|Yes
|string
|会場日程ID
|`ed282fd3-8ef5-426a-b1c3-c2a0fced1c13`

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "placeScheduleId": "ed282fd3-8ef5-426a-b1c3-c2a0fced1c13",
  "placeScheduleLockingStatus": 31
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
** 更新完了
* 400 BadRequest
** 指定した会場日程IDの形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 404 NotFound
** 指定した会場日程が存在しない
