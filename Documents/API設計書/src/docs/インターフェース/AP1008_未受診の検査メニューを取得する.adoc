== AP1008_未受診の検査メニューを取得する

=== 概要

* 受診番号入力画面から利用する
* 受診番号を指定して、未受診の検査メニューリストを取得する
* 検査メニューは表示順の昇順でソートする
* 検査項目明細単位の依頼レコードに対して、検査結果あるいは検査中止のレコードが存在すれば受診済みとする
* 未受診の検査項目明細が1つ以上存在する検査メニューを「未受診の検査メニュー」として返す

=== URI

[source]
----
[GET] /consult/{consultNumber}/unexaminedMenus
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|`012345678`

|===

=== クエリパラメータ

なし

=== リクエストボディ

なし
