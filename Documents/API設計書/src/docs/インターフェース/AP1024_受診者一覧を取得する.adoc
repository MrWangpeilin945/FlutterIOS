== AP1024_受診者一覧を取得する

=== 概要

* 検査メニューの受診者一覧を取得して返却する
* 受診者一覧画面から利用する

=== URI

[source]
----
[GET] /examinees/placeSchedules/{placeScheduleId}/examMenus/{examMenuId}
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|status
|No
|number
|進捗状況
|11

|===

=== リクエストボディ

なし
