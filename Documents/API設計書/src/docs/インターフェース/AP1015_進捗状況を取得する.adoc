== AP1015_進捗状況を取得する

=== 概要

* 会場日程を指定して、検査項目ごとの進捗状況を取得する
* 検査項目の表示順の昇順でソートする。
* `status` は集計検査進捗状況（ `AggregatedProgressStatus` ）を使用する。

=== URI

[source]
----
[GET] /progress/{placeScheduleId}
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|placeScheduleId
|Yes
|string
|会場日程ID
|`ed282fd3-8ef5-426a-b1c3-c2a0fced1c13`

|===

=== クエリパラメータ

なし

=== リクエストボディ

なし
