== AP1015_進捗状況を取得する

=== 概要

* 会場日程を指定して、検査項目ごとの進捗状況を取得する
* `status` は集計検査進捗状況（ `AggregatedProgressStatus` ）を使用する。

=== URI

[source]
----
[GET] /progress/{placeScheduleId}
----

=== 仕様補足

進捗の算出ロジックが複雑なため補足する。

==== 進捗の算出方法

このAPIで取得する進捗は、「受診のステータス」と「検査依頼に対する結果」を組み合わせて計算する。

具体的な計算方法を以下に記載する。

* 検査項目明細単位の依頼に対して
** 結果レコードあり => 検査済み
** 中止レコードあり => 検査中止
** 上記のレコードなし => 未実施
* 検査項目単位にグルーピングして
** 未実施が1つでもあれば => 未実施
** すべて検査中止であれば => 検査中止
** 上記以外で検査済みを含む => 検査済み
* 検査項目単位のステータスと受診のステータスの組み合わせで集計用の進捗を計算する
** [検査項目]未実施 x [受診]来場待ち => 予定11
** [検査項目]未実施 x [受診]検査中 => 来場21
** [検査項目]検査済み x [受診]検査中 => 済41
** [検査項目]検査中止 x [受診]検査中 => 中止51

検査依頼をベースにして集計するため、検査依頼が存在しなければ計上されない。
