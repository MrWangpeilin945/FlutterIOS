= アプリケーション設定

アプリケーション設定の一覧です。

* `app_config` テーブルに設定します。
* キーは分類のためにドットで区切りますが、アプリケーション内部では階層構造を持ちません。
* テーブル構造の都合上、設定値はすべて文字列型ですが数値で設定が必要なものもあります。
* 原則、構築時にすべてのレコードを挿入しますが、万一レコードがない場合はデフォルト値で補完します。
* 個別機能の設定は専用のテーブルを作ります。アプリケーション設定は全体に共通の設定のみ扱います。
