== AP005_未受診の健診メニュー取得

=== 概要

* 予約No入力画面から利用する
* 予約Noを指定して、未受診の健診メニューリストを取得する
* 健診メニューは表示順の昇順でソートする

=== URI

[source]
----
[GET] /consult/{reservationNo}/unexaminedMenus
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|reservatioNo
|Yes
|string
|予約No
|`012345678`

|===

=== クエリパラメータ

なし

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "unexaminedMenus": [
    {
      "健診メニューID": 3,
      "健診メニュー名": "身体計測"
    },
    {
      "健診メニューID": 9,
      "健診メニュー名": "血圧"
    }
  ]
}
----

=== ステータスコード

* 200 OK
* 400 BadRequest
** 入力した予約Noの形式が不正である
* 404 NotFound
** 予約Noの受診データが存在しない
