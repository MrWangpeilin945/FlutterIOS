== AP1017_会場ロック状態を更新する

=== 概要

* 健診完了の状態を更新して登録する

=== URI

[source]
----
[PUT] /placeSchedules/{placeScheduleId}/placeScheduleLockingStatus
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|placeScheduleId
|Yes
|number
|会場日程ID
|54

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "placeScheduleId": 15,
  "placeScheduleLockingStatus": 2
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
** 更新完了
* 400 BadRequest
** 指定した会場日程IDの形式が不正
* 404 NotFound
** 指定した会場日程が存在しない
