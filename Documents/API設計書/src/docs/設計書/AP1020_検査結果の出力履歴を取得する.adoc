== AP1020_検査結果の出力履歴を取得する

=== 概要

* 検査結果を出力した履歴を取得する
* 出力日時の降順でソートする

=== URI

[source]
----
[GET] /integrations/examResults/exportHistory
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

なし

{
  "exportHistories": [
    {
      "placeScheduleId": 23,
      "placeName": "会場B",
