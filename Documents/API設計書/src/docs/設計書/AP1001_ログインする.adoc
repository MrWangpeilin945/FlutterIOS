== AP1001_ログインする

=== 概要

* 職員IDとパスワードを渡して認証用のトークンを取得する
* テナントIDはサブドメインから取得するため、リクエストボディでは扱わない

=== URI

[source]
----
[POST] /login
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "staffId": 12345,
  "password": "sKgj3c83JXJWXs"
}
----

=== レスポンスボディ

[source,json]
----
{
  "token":"cgNUZ8ZP5prD2g..."
}

----

=== ステータスコード

* 200 OK
