== AP1019_連携用に検査結果を出力する

=== 概要

* 検査結果の出力処理をトリガーする
* このAPIを実行すると外部システム用にデータ出力する

=== URI

[source]
----
[POST] /integrations/examResults/{placeScheduleId}/export
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|placeScheduleId
|Yes
|number
|出力対象の会場日程ID
|28

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "placeScheduleId": 28
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
* 400 BadRequest
** 指定した会場日程IDの形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 404 NotFound
** 指定した会場日程が存在しない
