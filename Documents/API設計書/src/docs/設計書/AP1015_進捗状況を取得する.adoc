== AP1015_進捗状況を取得する

=== 概要

* 会場日程を指定して、検査項目ごとの進捗状況を取得する
* 検査項目の表示順の昇順でソートする。

=== URI

[source]
----
[GET] /progress/{placeScheduleId}
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|placeScheduleId
|Yes
|number
|会場日程ID
|12

|===

=== クエリパラメータ

なし

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "placeScheduleId": 12,
  "placeName": "会場A",
  "examDate": "2024-10-21",
  "progress": [
    {
      "examItemId": 3,
      "examItemName": "検査項目A",
      "details": [
        {
          "status": 1,
          "statusName": "予定",
          "count": 0
        },
        {
          "status": 2,
          "name": "受診済み",
          "count": 8
        }
      ]
    }
  ]
}
----

=== ステータスコード

* 200 OK
* 401 Unauthorized
** JWT認証に失敗
