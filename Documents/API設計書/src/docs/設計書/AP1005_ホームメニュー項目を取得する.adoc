== AP1005_ホームメニュー項目を取得する

=== 概要

* ホーム画面の表示に必要なホームメニューを取得する
* ホームメニューの項目は設定したグループでグルーピングする
* グループとグループ内の項目は表示順の昇順でソートする
* 会場日程を選択済みのとき使用できる項目を判別するために、使用可能条件を使用する。現状は`placeScheduleSelected"`の1つだが、将来的な拡張の余白を残すためリスト型で定義する。

=== URI

[source]
----
[GET] /homeMenus
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

なし

----
{
  "homeMenuGroups": [
    {
      "groupName": "一般",
      "menus": [
        {
          "menuName": "進捗",

          "availableConditions": ["placeScheduleSelected"]
        }
      ]
    },
    {
      "groupName": "外部システム連携",
      "menus": [

          "availableConditions": []
        }
      ]
    }
  ]
}
----
