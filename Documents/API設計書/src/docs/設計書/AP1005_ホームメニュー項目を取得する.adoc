== AP1005_ホームメニュー項目を取得する

=== 概要

* ホーム画面の表示に必要なホームメニューを取得する
* ホームメニューの項目は設定したグループでグルーピングする
* グループとグループ内の項目は表示順の昇順でソートする

=== URI

[source]
----
[GET] /homeMenus
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "homeMenuGroups": [
    {
      "groupName": "一般",
      "menus": [
        {
          "menuName": "進捗",
          "path": "progress"
        }
      ]
    },
    {
      "groupName": "外部システム連携",
      "menus": [
        {
          "menuName": "健診結果出力",
          "path": "examResultsExport"
        },
        {
          "menuName": "健診結果出力履歴",
          "path": "examResultsExportHistory"
        }
      ]
    }
  ]
}
----

=== ステータスコード

* 200 OK
