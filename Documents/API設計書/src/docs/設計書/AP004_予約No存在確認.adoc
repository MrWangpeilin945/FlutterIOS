== AP004_予約No存在確認

=== 概要

* 予約No入力画面から利用する
* 予約Noの受診が存在するかどうか確認する
* 受診が存在するかのみ確認してその他の責務を持たない

=== URI

[source]
----
[POST] /consult/reservationNo/verify
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "reservationNo": "15"
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
** 入力した予約Noの受診データが存在する
* 400 BadRequest
** 入力した予約Noの形式が不正である
* 404 NotFound
** 入力した予約Noの受診データが存在しない
