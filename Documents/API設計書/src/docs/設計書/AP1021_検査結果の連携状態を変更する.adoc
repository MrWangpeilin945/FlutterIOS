== AP1021_検査結果の連携状態を変更する

=== 概要

* 受診単位の連携状態を変更する
* 結果出力後に連携状態を引き戻して再処理したいときなどに使用する

=== URI

[source]
----
[PUT] /consult/{consultNumber}/integrationStatus
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|00123

|===

=== クエリパラメータ

なし

=== リクエストボディ

[source,json]
----
{
  "consultNumber": 15,
  "integrationStatus": 1
}
----

=== レスポンスボディ

なし

=== ステータスコード

* 200 OK
* 400 BadRequest
** 指定した受診番号の形式が不正
* 401 Unauthorized
** JWT認証に失敗
* 404 NotFound
** 指定した受診が存在しない
