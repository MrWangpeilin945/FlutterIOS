== AP1009_検査結果入力情報を取得する

=== 概要

* 検査結果入力画面から利用する
* 検査結果入力画面を構成するための情報を取得する

=== URI

[source]
----
[GET] /consult/{consultNumber}/inputExamItems
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|consultNumber
|Yes
|string
|受診番号
|`012345678`

|===

=== クエリパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|examMenuId
|Yes
|number
|検査メニューID
|3

|===

=== リクエストボディ

なし

* 200 OK
* 400 BadRequest
