== AP1002_職員の情報を取得する

=== 概要

* 職員の情報を取得する
* 操作者を画面に表示する際に使用する

=== URI

[source]
----
[GET] /staffs/{staffId}
----

=== リクエストヘッダー

=== パスパラメータ

[cols="2,1,1,4,2" options="header"]
|===
|名称|必須|型|説明|具体例

|staffId
|Yes
|number
|取得する職員の職員ID
|123

|===

=== クエリパラメータ

なし

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "staffId": 1234,
  "staffName": "両備 太郎"
}
----

=== ステータスコード

* 200 OK
* 404 NotFound
** 指定した職員IDの職員が存在しない場合
