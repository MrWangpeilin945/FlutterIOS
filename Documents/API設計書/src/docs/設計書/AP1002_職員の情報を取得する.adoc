== AP1002_職員の情報を取得する

=== 概要

* ログイン中の職員情報を取得する
* 操作者を画面に表示する際に使用する

=== URI

[source]
----
[GET] /staff/profile
----

=== リクエストヘッダー

=== パスパラメータ

なし

=== クエリパラメータ

なし

=== リクエストボディ

なし

=== レスポンスボディ

[source,json]
----
{
  "staffId": 1234,
  "staffName": "両備 太郎"
}
----

=== ステータスコード

* 200 OK
* 404 NotFound
** 指定した職員IDの職員が存在しない場合
