= 視力（遠・近）

視力には遠方視力・近方視力があり、それらを区別して返却します。

== 命名

プロパティ名は以下の命名の組み合わせで命名します。

[options="header",cols="1,2"]
|===

|区分
|命名

|裸眼視力 / 矯正視力
|naked / corrected

|左眼 / 右眼 / 両眼
|Left / Right / Both

|遠方視力 / 近方視力
|DV (Distance Vision) / NV (Near Vision)

|===

== 結果値

[options="header",cols="1,1,2"]
|===

|計測結果
|型
|値

|視力
|Number
|測定できた視力を数値として返します

|視力 測定不能（0.1未満）
|Number
|0

|視力 測定なし
|null
|null

|===
