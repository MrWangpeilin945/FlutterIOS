= 聴力

聴力の検査には選別・閾値があり、それぞれで返す内容が異なります。

== 命名

プロパティ名は以下の命名の組み合わせで命名します。
※選別聴力は1000Hz, 4000Hzのみ

[options="header",cols="1,2"]
|===

|区分
|命名

|選別聴力 / 閾値聴力
|screening / monitoring

|検査周波数
|250Hz / 500Hz / 1000Hz / 2000Hz / 4000Hz / 8000Hz

|左耳聴力 / 右耳聴力
|Left / Right

|===

== 結果値

[options="header",cols="1,1,2"]
|===

|計測結果
|型
|値

|選別聴力 所見なし
|String
|1

|選別聴力 所見あり
|String
|2

|閾値聴力
|Number
|計測できた閾値聴力を負の数、0を含む数値として返します

|閾値聴力 スケールアウト
|Number
|999

|選別聴力 / 閾値聴力 測定なし
|null
|null

|===

※スケールアウトは測定できる上限の音の大きさでも聞き取れなかった場合を指します
