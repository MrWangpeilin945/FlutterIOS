= 概要

ここではWELLSHIPのfrontendと機器連携アプリ間の連携について概要を記述します。

== 用語

=== frontend

Webブラウザで表示されるWELLSHIPのサイトを指します。

=== 機器連携アプリ

検査機器とタブレット間の通信を担うネイティブアプリを指します。

=== 機器連携結果受領ページ

機器連携アプリは、検査機器から受信したデータが所定の終了条件を満たしたとき、起動時のパラメータとして指定したURLをブラウザで開きます。

このURLには検査機器から受信したデータをクエリパラメータとして付与しており、機器連携結果受領ページはこのクエリパラメータの内容をlocalstorageに格納したあとタブを閉じます。

=== 結果解析スクリプト

検査機器から受信するデータは機器やメーカーごとにレイアウトが異なるため、この差異を吸収するためのスクリプトです。

frontendはlocalstorageから取得した機器連携結果をこのスクリプトで変換することで、どの機器と通信したかを意識せず計測結果を扱えます。

このスクリプトで返すオブジェクトのことを計測結果オブジェクトと呼びます。
